# STRATEGIC ARSENAL

지도 기반 무기 효과 **시뮬레이션** 게임입니다. 화면 효과만 보여 주며, 무기의 원리나 구조는 다루지 않습니다.

- 무기 70종 · 방어 체계 10종
- 화면: 2D 지도 · 3D 시점 · 30km 미니어처 디오라마 · 지구본
- 기능: 시네마 카메라, 슬로모션·시간 막대, 전후 비교, 위력 비교, 분위기(시간대·날씨), 사진 모드, 🎥 녹화, 🏃 대피 연출, 🌅 시간 흐름, 📊 피해 그래프, 📖 무기 정보 카드, 🔊 거리별 소리, 방어 작전(6단계·정비 시간·웨이브 예고·점수), 시나리오, 검색·즐겨찾기, 장면 저장·공유, 📲 앱처럼 설치
- 지도와 도시는 모두 가상이며, 피해 수치는 공개 자료를 바탕으로 한 게임용 근사값입니다.

## 사용한 자료
- 3D 엔진: three.js (MIT)
- 일부 3D 모델: Kenney City Kit (kenney.nl, CC0)
- 지구 지형: Natural Earth (공공 영역)
